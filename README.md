# Futebolísticos ⚽

**Projeto acadêmico de Front-End** desenvolvido em grupo para apresentar informações sobre o futebol por meio de um site com páginas interligadas.

### 🌐 Acesse o site

**[Visualizar o Futebolísticos no GitHub Pages](https://devaxl64.github.io/Futebolisticos/introducao.html)**

## Objetivo

Aplicar os conhecimentos de **HTML e CSS** na criação e organização de páginas web, reunindo diferentes temas relacionados ao futebol em um único site. Cada integrante desenvolveu uma parte do conteúdo, que foi integrada ao projeto da turma.

## Conteúdo do site

O projeto apresenta:

- Origem e história do futebol e dos primeiros clubes;
- Principais times brasileiros e internacionais;
- Identidade dos clubes, torcidas e cultura do futebol;
- Competições, títulos e conquistas;
- Grandes jogadores que marcaram a história do esporte;
- Futebol na atualidade e uso da tecnologia no esporte;
- Um formulário demonstrativo relacionado ao futebol.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas, textos, imagens, links e formulário;
- **CSS3:** apresentação visual e estilização;
- **GitHub Pages:** publicação do site para acesso pelo navegador.

## Organização do projeto

- `index.html` — página sobre o início do futebol;
- `introducao.html` — página de boas-vindas;
- `grandes-jogadores.html` — conteúdo sobre jogadores históricos;
- `principais_competicoes.html` — competições de futebol;
- `futebol_atualmente.html` — futebol na atualidade;
- `tecnologia.html` — tecnologias aplicadas ao esporte;
- `formulario.html` — formulário de demonstração;
- `css/` — arquivos de estilo;
- `imagens/` — imagens utilizadas nas páginas.

As demais páginas HTML completam os outros temas apresentados no menu do site.

## Sobre o trabalho

O **Futebolísticos** é um trabalho coletivo da disciplina de **Front-End**, realizado com finalidade **educacional**, para praticar a estruturação, a estilização e a integração de páginas web.

> **Observação:** o formulário faz parte da demonstração acadêmica. Ele não envia nem armazena dados; não deve ser utilizado para cadastrar pessoas reais.
